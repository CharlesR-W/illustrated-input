# Illustrated Input (public bundle)

This directory is generated by `build.mjs` in the private source
repository. Do not edit it by hand: changes are overwritten on the next build.

It contains only the static reader (`index.html`, `styles.css`, `core.js`, `app.js`),
the course index `content/courses.json` that the reader's course selector reads, and for
each course its `course.json`, the written lesson files, `lexicon.json`, and the media
those files reference:

- Мир (`ru-mir-01`, draft): `content/ru/`
- Мир: ускоренный курс (`ru-mirc-01`, draft): `content/ru-mirc/`
- Ἐν Σκιλλοῦντι (`grc-skil-01`, draft): `content/grc/`
- Y Brenin a Fu ac a Fydd (`cy-brenin-01`, published): `content/cy/`
- Kvöldvakan (`is-kvold-01`, draft): `content/is/`
- Il libro e la via (`it-dante-01`, draft): `content/it-dante/`

- La puerta del patio (`es-NEW-01`, draft): `content/es/`
- La porta aperta (`it-NEW-01`, draft): `content/it/`

## Suggest a language

Want a course in another language? See [CONTRIBUTING.md](CONTRIBUTING.md): point a coding
agent at it and it will interview you and file a
[language spec issue](https://github.com/CharlesR-W/illustrated-input/issues/new?template=language-spec.yml).
Pull requests here are overwritten by the next build, so specs arrive as issues.

GitHub Pages serves it from the root of the `main` branch. No build step, account or API
key is needed; to read it locally run `python -m http.server` here and open
http://localhost:8000.

If you used the earlier Welsh course, delete the old "Y Brenin a Ddaw Eto" Anki deck: card
IDs changed with the new course.
